FTL Me

A bookmark that runs on a FencingTime Live page and shows one fencer's pool and strip, pool ranking, each DE bout (opponent, strip, time) and final place. It reads the same pages you can see when signed in; nothing is sent anywhere else.

1. Set up the bookmark (once)

Fencer's last name (add the first name if two fencers share it). You can change it later in the panel.

Android Chrome
  1. Tap Copy code. If that fails, long-press in the box, then Select all and Copy.
  2. Bookmark this page (⋮ menu, then ☆).
  3. Open the bookmark editor (⋮, Bookmarks, long-press the new bookmark, Edit). Set the name to fm.
  4. In the URL field, delete everything, type javascript: by hand, then paste right after it. Chrome removes javascript: from pasted text, and without it the edit is silently discarded.
  5. Tap the back arrow to save. Reopen the bookmark: the URL must start with javascript:(function.
Desktop Chrome

Drag this to the bookmarks bar: fm

The bookmark loads the current code from this site each time it runs, so updates need no new bookmark.

2. At the tournament

  1. Sign in to fencingtimelive.com and open the tournament schedule, or any page of your event. From the schedule it finds the event the fencer is entered in, or asks which one if there are several.
  2. Tap the address bar, type fm, and tap the suggestion with the star. The Google search suggestion only searches. Tapping the bookmark in the Bookmarks list does nothing on Android.
  3. Leave the tab open. One run lasts the whole tournament.

3. Refreshing

  • Auto-refresh every 30 s is on by default. Untick it to stop; the choice is remembered.
  • Refresh updates at once.
  • Pool details and Full tableau open in a new tab, so the panel keeps running in its own tab.
  • If you closed the panel, navigated away, or the phone reloaded the page, run fm again.
  • change switches to another fencer. Close removes the panel and shows the FTL page underneath.

What shows when

FTL posts each stage only when it is ready, so cards fill in over the day.

  • Entry: before pools are posted, confirms the fencer is in the entry list.
  • Pool: pool number, strip and start time, bouts so far, a link to the pool sheet, and how many pools are complete.
  • Pool ranking: place, V/M and indicator, marked provisional until every pool is in, then Advanced or Eliminated.
  • Direct elimination: once the tableau is posted, the next bout (strip, opponent, time) and every result so far. Show me in the tableau opens the bracket scrolled to the fencer's latest position.
  • Final result: place once the fencer is out or has won.

Only the first pool round and first tableau of an event are read.
